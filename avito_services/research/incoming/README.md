# Материалы на проверку

Имя файла: YYYY-MM-DD-тема-автор.md. Укажи ID вопроса, ответ, источник, охват, ограничение и затронутый слайд. Рецензент фиксирует решение (принято, нужна проверка, отклонено), дату и основание. Принятые выводы переносятся в evidence.md и соответствующий раздел защиты; исходная карточка остаётся доступной.
